# Kireta Care Foundation Website

A responsive multi-page website for Kireta Care Foundation in Budaka District, Uganda.

## Preview
Open `index.html` in a browser. Keep the `assets` folder, `styles.css`, and `script.js` in the same project folder.

## Pages
Home, Our Story, Our Programmes, Kireta Care Primary School, Our Team, Gallery, Contact.

## Before publishing
- Add the Foundation's official email address and telephone number to `contact.html`.
- Confirm current school statistics and programme descriptions.
- Add the original photographs of women using tailoring machines, the youth brick-making activity, and farming activities to the relevant programme sections and gallery. The tailoring, sewing-machine, brick-making, community gathering and school-compound photographs supplied on 13 November 2026 are now included. Add farm-specific photographs when available.
- Check that the official logo artwork is approved for use with the shortened public-facing name “Kireta Care Foundation”.
